# Outils de gestion de dépendances

Scripts Python pour gérer les dépendances IBM i.

## Utilisation

### Installation des dépendances

```bash
python .vscode-deps/install_deps_v2.py
```

### Migration v1 → v2

```bash
python .vscode-deps/migrate_v1_to_v2.py
```

## Installation

```bash
pip install jsonschema
```
